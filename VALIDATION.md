Точный шифртекст проверен по независимому расчёту с массивами клеток. Пример скремблера из PDF воспроизведён по всем восьми строкам. Период каждого поддерживаемого многочлена проверен для всех его ненулевых начальных ключей; период общей выходной гаммы для выбранных ключей — 465 бит. Дополнительно проверена ситуация, когда два одинаковых регистра дают постоянный нулевой XOR-выход.

Готовые результаты находятся в `examples/`. Автоматические проверки новых изменений настроены в `.github/workflows/go.yml`.
